### 1. Guess My Age
A simple Python guessing game.
#### Features

- Generates a random age between 1 and 100
- Gives the player 5 attempts
- Provides "Too high" and "Too low" hints

#### Python Concepts Used
  - Functions
- Loops
- Conditional statements
- User input
- Exception handling
- Random module
  
#### How to Run
  ```bash
python guess_my_age.py
